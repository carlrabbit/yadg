# HR-M0009-01 — Microsoft Word Finalized Artifact Quality

## Owner

M0009 — Microsoft Word renderer and publishing.

## Review subject

A representative synthetic DOCX finalized by the M0009 `word` renderer on the same repository revision used for completion evidence.

The fixture should exercise, where applicable:

- ordinary section/content authoring;
- figure including generated Mermaid image;
- generated/prepared table;
- captions and `SEQ`;
- semantic `REF`;
- numbered section reference;
- template-owned TOC/list structure.

## Required evidence before review

The implementation ledger/review evidence identifies:

- repository revision;
- Windows/OS version;
- Microsoft Word version;
- authored input identity/hash;
- finalized DOCX identity/hash;
- successful real Word Tier-3 command/result.

The reviewer must have access to the finalized DOCX.

## Human acceptance

Open the finalized DOCX in Microsoft Word and confirm:

- Word opens it without repair/error prompt;
- template presentation remains materially intact;
- figures are visible and plausibly sized/positioned;
- generated/prepared tables are intact;
- captions/numbering display current values;
- semantic references display current values;
- TOC/list structures included by the fixture show current entries;
- no unresolved YADG controls are visible;
- no obvious finalization-induced pagination/layout corruption is present.
