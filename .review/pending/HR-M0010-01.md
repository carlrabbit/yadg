# HR-M0010-01 — Realistic Document Composition Quality

## Owner

M0010 — Realistic document composition and template compatibility.

## Review subject

Two representative finalized artifacts produced from the committed application-origin fixtures on the same repository revision used for completion evidence:

1. Microsoft-Word-origin template -> YADG build -> Microsoft Word renderer;
2. LibreOffice-Writer-origin template -> YADG build -> LibreOffice renderer.

The Tier-3 evidence must additionally show successful cross-render completion for Word-origin -> LibreOffice and LibreOffice-origin -> Word.

## Required evidence before review

The implementation evidence identifies:

- repository revision;
- Windows/OS version;
- Word version;
- LibreOffice version;
- fixture provenance records and committed fixture SHA-256 values;
- authored/finalized artifact hashes for all four Tier-3 matrix paths;
- successful `./eng/test-m0010-tier3.ps1` result.

The reviewer must have access to the two representative finalized DOCX files.

## Human acceptance

Open each representative artifact in its corresponding application and confirm:

- no repair/conversion warning requiring intervention;
- non-default page/section layout remains materially intact;
- static template paragraphs/layout survive;
- headers and footers remain intact, including page fields and substituted values;
- footnote, endnote, and comment values are visibly substituted;
- text-box/shape value is visibly substituted without destroying the shape/layout;
- heading hierarchy is visibly correct for both `section` and `content` insertion below an existing template outline level 4;
- ordinary inserted Markdown paragraphs remain separate and use the intended body presentation;
- representative tables, figures, captions, references, TOC/list structures remain plausible/current;
- no YADG controls expected to be consumed remain visible;
- no obvious YADG-induced pagination/layout corruption is present.
